# QuickNotes

QuickNotes is a simple, responsive note-taking web application built with HTML, CSS, and JavaScript. It helps users capture ideas, organize notes into Personal, Work, and Study categories, search saved notes, and manage their notes in one place.

## Features

- Add notes with a selected category.
- Validate notes to prevent empty entries and notes longer than 200 characters.
- Display each note's category and creation date.
- Delete individual notes.
- Search notes by text without case sensitivity.
- Save notes in browser localStorage so they remain after refreshing.
- Display an accurate count of saved notes.
- Responsive layout for mobile and desktop screens.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage
- Git and GitHub

## How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/quicknotes-app.git
   ```

2. Enter the project folder:

   ```bash
   cd quicknotes-app
   ```

3. Open the folder in Visual Studio Code:

   ```bash
   code .
   ```

4. Open `index.html` using the Live Server extension, or open the file directly in your browser.

No additional packages or installation commands are required.
